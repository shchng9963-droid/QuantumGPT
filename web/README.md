# QuantumGPT — research demo dashboard

A 3-page Streamlit app that backs the paper.

## Pages

- **Home** (`web/app.py`) — claims, headline stats, the five showcase figures.
- **Trace replay** (`web/pages/1_🔍_Trace_replay.py`) — pick a real (drift profile, circuit, seed) trace and step through every ReAct call plus the verifier verdict.
- **Benchmark explorer** (`web/pages/2_📈_Benchmark_explorer.py`) — filter the full 1,615-row paired benchmark by system, drift profile, circuit. Per-circuit Δ forest and full-distribution strip plot recompute live.

## Run

From repo root:

    streamlit run web/app.py --server.port 8501

Then browse http://localhost:8501. Use the page selector in the sidebar to switch.

## What it reads

- `figures/showcase/*.png` — generated by `scripts/make_showcase_figures.py`.
- `eval/results/v3_main_merged/result_summary.jsonl` — Sprint A 1,125 rows (5 systems × 225).
- `eval/results/v3_orchestrator*/result_summary.jsonl` — Sprint B Orchestrator runs.
- `eval/results/v3_harder_rerun/result_summary.jsonl` — harder regime rerun.
- `eval/results/public_mqtbench_agent_deepseek_10tasks_3seeds/QuantumGPT-Full/.../post_drift_trace.json` — concrete ReAct traces for replay.
- `eval/results/verifier_reliability.json` — 10-case injection battery.
- `eval/stats/v3_g3/*.json` — paired Wilcoxon + bootstrap CI.

## Cache

`@st.cache_data` is set on every loader, so per-page reload is instant after the first run.

## Adding a page

Drop a new `web/pages/N_emoji_name.py`, import from `qgdata` (renamed from `data` to dodge a top-level collision with the project's `data/` package). Streamlit picks it up automatically.
